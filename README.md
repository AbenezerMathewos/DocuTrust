# DocuTrust

DocuTrust is a full-stack application built for secure document management and trust.

## Project Structure

- `frontend/` - Contains the frontend user interface and client-side logic.
- `backend/` - Contains the backend API server, database configuration, and business logic.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- MongoDB

### Backend Setup

1. Navigate to the `backend/` directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```

### Frontend Setup

1. Navigate to the `frontend/` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
